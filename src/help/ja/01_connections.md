# 接続

左ペイン下段の接続から、登録済みのサーバーを選びます。現在の接続は 1 つだけで、
スキーマ・マニフェスト・オペレーションの各ページはすべてその接続を見ます。

## 手順

1. 接続を選ぶか、追加する。
2. ホスト・ポート・データベース・ユーザーを入れる。パスワードは暗号化して保存されます。
3. 「接続を確認」で疎通を見る。
4. 「現在の接続にする」で切り替える。切り替えると一覧が読み直されます。

## 保存先

接続はアプリのデータディレクトリに暗号化して保存されます。設定ファイルを直接編集する
必要はありません。ブラウザで `pnpm dev` を起動した場合は Tauri の IPC が無いため、
接続一覧は空で表示されます。実データを見るときは `pnpm tauri dev` を使ってください。
