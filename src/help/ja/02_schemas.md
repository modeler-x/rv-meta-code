# スキーマ

接続中のサーバー配下のスキーマが並びます。ここで扱うのは**管理対象にするかどうか**と
**OpenAPI を生成するかどうか**だけです。宣言の中身は扱いません。

## 手順

1. 行を選ぶ。複数選べます。
2. 「生成」で OpenAPI を生成する。生成には manifest が要ります。
3. 「開く」でそのスキーマのマニフェストへ移動する。移動するだけで、宣言は作りません。

## ラベル

- **作成済み** — そのスキーマに manifest がある
- **未作成** — manifest がない。オペレーションもドキュメントも作れません

宣言が何件埋まっているかはマニフェストの責務なので、ここには出しません。
